A two-line robot confession — 196 characters. Line one owns one specific,
human-scale mistake: texting the boss about a dentist appointment at 3 a.m.
after mixing up two contacts both named Alex. Line two names the lesson that
follows from exactly that mistake: check the full name first, and confirm
the recipient before sending anything.

## How to run

```sh
node main.ts   # writes /output/entry.txt
```

`main.ts` uses only the Node standard library, validates the entry (two
lines, each one sentence, under 200 characters) and writes the same bytes on
every run. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
